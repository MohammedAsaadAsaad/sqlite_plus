## DB Browser readiness

A Flutter browser can list schema, page rows, edit cells, and run SQL only for files and statements this engine already opens. The items below are the engine gaps that block the same actions on an arbitrary official SQLite file. B1, B2, and B4 passed their gates. B3 stays open while any part below is open. B5 is not done. M9 stays unchecked. Item 108 stays open. Each item needs its own pinned SQLite 3.53.1 comparison before it can be checked. Do not reduce the measured cost of the current read and write paths.
